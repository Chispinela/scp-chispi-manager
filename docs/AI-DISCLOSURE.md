# AI disclosure

**SCP Chispi Manager was developed with extensive AI assistance.** This is intentionally stated prominently in the README.

The project owner specified the requirements, name, visual direction, and requested changes. OpenAI ChatGPT/Codex generated and revised substantial portions of the implementation, interface, translations, tests, build configuration, troubleshooting changes, and documentation. This is a human-directed project with substantial AI-generated and AI-edited material; it should not be described as entirely hand-written software.

The owner supplied the original logo reference. OpenAI ImageGen prepared a transparent version while preserving that design. The Windows icon was converted from the PNG. See [logo provenance](logo.md).

Generated work is not, by itself, proof that a feature works. [Verification](VERIFICACION.md) distinguishes automated checks, real local game-server tests, controlled fault injection, and untested scenarios. Automated Windows build-selection tests are not physical tests on every Windows release. A controlled stalled-helper test does not prove that a remote computer's original filesystem issue has been resolved.

When reporting a problem, include the app version, Windows build, reproduction steps, and a reviewed diagnostic export if helpful. Remove private details before posting publicly. Contributions, including AI-assisted ones, still need review and appropriate testing.

This independent project is not endorsed or maintained by OpenAI, Northwood, Valve, Microsoft, or Radmin.
