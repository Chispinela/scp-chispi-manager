# Logo provenance

The project owner supplied `assets/logo-original.png` as the original reference.

`assets/logo.png` is the transparent version used by the application. It was prepared with **OpenAI ImageGen**, preserving the supplied design and lettering while removing the background. `assets/icon.ico` was converted from that PNG for Windows. This is part of the project's disclosed AI-assisted development process; see [AI disclosure](AI-DISCLOSURE.md).

The original editing prompt was:

> Use case: background-extraction. Edit target: provided SCP Chispi Manager logo. Remove ONLY the flat green background and make it truly transparent. Preserve the purple SCP emblem, server towers, lightning, all original lettering and exact design. No redesign, no additions. Text must remain SCP CHISPI, MANAGER, SERVER MANAGER UNIT. Output the clean logo centered, cropped closely with a little transparent margin. Asset type: Windows desktop app splash screen logo.
